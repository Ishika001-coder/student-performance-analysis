# Student Performance Analysis

## Project Overview

This project analyzes student performance and learning behaviour using a dataset containing academic and learning-related information.

The main objective is to explore the dataset, identify patterns and relationships, and understand how different learning-related variables are associated with students' exam performance.

## Objectives

- Explore and understand the dataset.
- Check data quality and missing values.
- Analyze student exam performance.
- Examine relationships between study hours, attendance, assignment completion, motivation, stress level, learning style, gender, and exam scores.
- Create visualizations to communicate important patterns.
- Summarize the key findings, conclusion, and limitations.

## Dataset

**Dataset:** Student Performance and Learning Behaviour Dataset

**Dataset Link:** Add the original/public dataset URL here.

The dataset used in the analysis contains 14,003 student records and 16 attributes. The analysis found no missing values.

## Setup and Run Instructions

1. Install Python 3.x.
2. Install the required libraries:

```bash
pip install -r requirements.txt
```

3. Open Jupyter Notebook:

```bash
jupyter notebook
```

4. Open `analysis.ipynb`.
5. Make sure the dataset file is available in the notebook's working directory.
6. Run the notebook cells from top to bottom.

## Limitations

The analysis describes patterns and relationships in the available dataset. Correlation and group comparisons do not prove cause and effect. Some categorical variables are coded, and their interpretation depends on the dataset documentation.
